3. Liên hệ 5 đặc tính NIST

  1. Tự phục vụ theo yêu cầu: Thao tác tạo Codespace cho phép yêu cầu môi trường phát triển qua giao diện mà không cần quản trị viên cài đặt trực tiếp trên từng máy.
  2. Truy cập mạng rộng: IDE được sử dụng qua trình duyệt; URL API đã mở thành công trên điện thoại khi cổng được đặt Public.
  3. Gộp tài nguyên: Codespace được cung cấp trên hạ tầng dùng chung của nhà cung cấp. API ghi nhận hostname codespaces-45fe99, nhưng riêng hostname chưa đủ chứng minh cách phân bổ tài nguyên vật lý.
  4. Co giãn nhanh: Việc yêu cầu cấp phát Codespace và tùy chọn thay đổi loại máy minh họa khả năng điều chỉnh tài nguyên. Bài này chưa thực nghiệm đổi loại máy hoặc tự động co giãn ứng dụng.
  5. Dịch vụ đo lường được: Billing Usage ghi nhận compute và storage, cho phép theo dõi mức sử dụng và số tiền tính phí.

4. Nhận xét

Codespaces cho phép xây dựng và chạy API trên môi trường đám mây bằng trình duyệt. Việc cấu hình môi trường có thể được dùng lại qua repository, giúp giảm thao tác cài đặt lặp lại trên máy cá nhân. Việc sử dụng vẫn phụ thuộc kết nối mạng và cần theo dõi hạn mức tài nguyên.

GitHub Pages phục vụ trang kết quả tĩnh này. API Express chỉ hoạt động khi Codespace và tiến trình ứng dụng đang chạy, với quyền truy cập phù hợp.
